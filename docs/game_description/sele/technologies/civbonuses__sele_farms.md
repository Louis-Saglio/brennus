# civbonuses/sele_farms

Seleucid-specific technology of 0 A.D. 0.28.0 — only the seleucids can get it. See `docs/game_description/sele/technologies/README.md` for the method; shared technologies are documented in `docs/game_description/generic/technologies/`.

## Basic stats

- **Name:** Fertile Crescent
- **Auto-researched:** yes
- **Requirements:** `{"any": [{"civ": "sele"}]}`
- **Effect:** Farms −25% wood cost and −75% build time.
- **Modifications:**

  - ×0.75 Loot/wood
  - ×0.25 Cost/BuildTime
- **Affects:** Field

## Seleucids

- auto-researched

Note: the Seleucid civ bonus. A field drops from 100 to 75 wood and from
50 s to 12.5 s build time, and yields 25% less wood loot if razed. Fields
are the cheapest way to lock in food income late-game (each supports up
to 5 gatherers with no walk), and sele's are the cheapest in the game —
pair this with the plentiful-farm early game (berries/hunting) and expand
onto grain once wood prices stop mattering. The bonus does not touch
gather rates, only the planting cost.
