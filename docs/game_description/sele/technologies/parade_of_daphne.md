# parade_of_daphne

Seleucid-specific technology of 0 A.D. 0.28.0 — only the seleucids can get it. See `docs/game_description/sele/technologies/README.md` for the method; shared technologies are documented in `docs/game_description/generic/technologies/`.

Data file: `simulation/data/technologies/parade_of_daphne.json`.

## Basic stats

- **Name:** Parade of Daphne
- **Cost:** 500 food, 300 metal
- **Research time:** 60 s
- **Requirements:** `{"all": [{"tech": "phase_city"}, {"civ": "sele"}]}`
- **Effect:** Champions −20% training time.
- **Modifications:**
  - ×0.8 Cost/BuildTime
- **Affects:** Champion

## Seleucids

- fortress

Note: a Seleucid fortress tech that shaves 20% off every champion's
training time — the cataphract, scythed chariot, armored war elephant,
and whichever infantry champion the army-reform pair unlocked. The
Seleucids field one of the widest champion rosters in the game (five
lines, matched only by pers), so this compounds: after the pair unlock
and the parade, champion-heavy play is distinctly faster to rebuild than
for other civs. Costs 500 food + 300 metal, so it pays for itself once a
few champions have queued.
