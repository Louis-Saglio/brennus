# units/heroes/ptol_hero_ptolemy_i_1

Ptolemaic-specific aura of 0 A.D. 0.28.0 — only the ptolemies can have it. See `docs/game_description/ptol/auras/README.md` for the method; shared auras are documented in `docs/game_description/generic/auras/`.

Data file: `simulation/data/auras/units/heroes/ptol_hero_ptolemy_i_1.json`.

## Basic stats

- **Name:** Patron of Construction
- **Type:** range
- **Radius:** 60 m
- **Affects:** Builder
- **Description:** Builders +10% build rate.
- **Modifications:**
  - ×1.1 Builder/Rate

## Ptolemaic

- attached by `units/ptol/hero_ptolemy_i`

Note: Ptolemy I's construction aura — all own Builder-class units within
60 m build 10% faster. It partially offsets the "Sun-dried Mud Bricks"
+50% build-time penalty on the Ptolemaic economy buildings, so parking
Ptolemy I at an expansion site is the standard way to plant civic centres
and colonies quickly. He carries the global "Mercenary Patron" aura on
top.
