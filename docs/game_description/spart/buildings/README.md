# Spartan-specific buildings of 0 A.D. 0.28.0

One file per building that **only the spartans** can build (single-civ structures of the `generic/buildings/` analysis). Stats are the fully resolved spart templates; the shared buildings are documented in `docs/game_description/generic/buildings/`.
