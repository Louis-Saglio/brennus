# ship_vision

Available to **15** civilisations. Generic (non-civ-specific) technology of 0 A.D. 0.28.0 — see `docs/game_description/generic/technologies/README.md` for the method.

Data file: `simulation/data/technologies/ship_vision.json`.

## Basic stats

- **Name:** Lookouts
- **Cost:** 60 food, 60 metal
- **Research time:** 40 s
- **Requirements:** `{"tech": "phase_village"}` — Unlocked in Village Phase.
- **Effect:** Ships and Boats +10% vision range; Scout Ships an additional +25% vision range. Unlocks “Exploration” for the Carthaginians and Han Chinese.
- **Modifications:**
  - ×1.1 Vision/Range
  - ×1.25 Vision/Range — ScoutShip
- **Affects:** Ship
