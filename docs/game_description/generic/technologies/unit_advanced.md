# unit_advanced

Available to **15** civilisations. Generic (non-civ-specific) technology of 0 A.D. 0.28.0 — see `docs/game_description/generic/technologies/README.md` for the method.

Data file: `simulation/data/technologies/unit_advanced.json`.

## Basic stats

- **Auto-researched:** yes
- **Effect:** Advanced and Elite units +20% training time, +25% health, +0.7 capture attack strength, +20% loot, and −30% gather speed; Healers +5 healing strength and +3 healing range; Melee units +10% attack damage; Ranged units −20% spread.
- **Modifications:**
  - +0.7 Attack/Capture/Capture
  - ×1.1 Attack/Melee/Damage/Hack — Melee
  - ×1.1 Attack/Melee/Damage/Pierce — Melee
  - ×1.1 Attack/Melee/Damage/Crush — Melee
  - ×0.8 Attack/Ranged/Projectile/Spread — Ranged
  - ×1.2 Cost/BuildTime
  - ×1.25 Health/Max
  - +3 Heal/Range — Healer
  - +5 Heal/Health — Healer
  - ×1.2 Loot/food
  - ×1.2 Loot/wood
  - ×1.2 Loot/stone
  - ×1.2 Loot/metal
  - ×1.2 Loot/xp
  - ×0.7 ResourceGatherer/BaseSpeed
- **Affects:** Advanced Unit Elite Unit
