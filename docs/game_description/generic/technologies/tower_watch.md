# tower_watch

Available to **15** civilisations. Generic (non-civ-specific) technology of 0 A.D. 0.28.0 — see `docs/game_description/generic/technologies/README.md` for the method.

Data file: `simulation/data/technologies/tower_watch.json`.

## Basic stats

- **Name:** Sentries
- **Cost:** 500 food
- **Research time:** 40 s
- **Requirements:** `{"tech": "phase_village"}` — Unlocked in Village Phase.
- **Effect:** Sentry and Stone Towers +50% default arrow count.
- **Modifications:**
  - ×1.5 BuildingAI/DefaultArrowCount
- **Affects:** SentryTower StoneTower GreatTower
