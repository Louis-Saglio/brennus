Available to **15** civilisations. Generic (non-civ-specific) technology of 0 A.D. 0.28.0 — see `docs/game_description/generic/technologies/README.md` for the method.

## Basic stats

- **Name:** Counterintelligence
- **Cost:** 400 food, 400 metal
- **Research time:** 60 s
- **Requirements:** `{"tech": "phase_city"}`
- **Supersedes:** unlock_spies
- **Effect:** Make your units 50% more expensive to bribe.
- **Modifications:**
