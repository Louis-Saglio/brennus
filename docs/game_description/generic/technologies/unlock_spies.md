# unlock_spies

Available to **15** civilisations. Generic (non-civ-specific) technology of 0 A.D. 0.28.0 — see `docs/game_description/generic/technologies/README.md` for the method.

Data file: `simulation/data/technologies/unlock_spies.json`.

## Basic stats

- **Name:** Espionage
- **Cost:** 500 food, 500 metal
- **Research time:** 60 s
- **Requirements:** `{"tech": "phase_city"}` — Unlocked in City Phase.
- **Effect:** Allows bribing the units of other players in order to share their vision.
