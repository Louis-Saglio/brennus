# cost_healer

Available to **15** civilisations. Generic (non-civ-specific) technology of 0 A.D. 0.28.0 — see `docs/game_description/generic/technologies/README.md` for the method.

## Basic stats

- **Name:** Sacrificial Ritual
- **Cost:** 250 food, 100 stone
- **Research time:** 40 s
- **Requirements:** `{"tech": "phase_town"}` — Unlocked in Town Phase.
- **Effect:** Healers –40% training time, and the metal cost is removed.
- **Modifications:**
  - ×0.6 Cost/BuildTime
  - = 0 Cost/Resources/metal
  - = 0 Loot/metal
- **Affects:** Healer !Champion !Hero
