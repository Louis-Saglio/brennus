# dock_efficiency

Available to **15** civilisations. Generic (non-civ-specific) technology of 0 A.D. 0.28.0 — see `docs/game_description/generic/technologies/README.md` for the method.

Data file: `simulation/data/technologies/dock_efficiency.json`.

## Basic stats

- **Name:** Shipwrights
- **Cost:** 200 food, 200 metal
- **Research time:** 40 s
- **Requirements:** `{"tech": "phase_town"}` — Unlocked in Town Phase.
- **Effect:** Docks work 20% faster (Ships −20% build time; Technologies −20% research time) and are built 20% faster. Unlocks special naval technologies for some civilizations.
- **Modifications:**
  - ×0.8 Cost/BuildTime — Ship
  - ×0.8 Cost/BuildTime — Dock
  - ×0.8 Researcher/TechCostMultiplier/time — Dock
