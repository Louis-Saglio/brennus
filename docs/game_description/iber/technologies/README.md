# Iberian-specific technologies of 0 A.D. 0.28.0

The iberians have **no civ-specific technologies** in 0 A.D. 0.28.0: no
tech file carries an exclusive `civ: iber` requirement, and there are no
`civbonuses/iber_*` auto-techs. The Iberian civ bonuses are implemented
elsewhere — "Massive Towers" in the `structures/iber/defense_tower`
template and "Starting Walls" through the skirmish map replacements —
see [`../civ.md`](../civ.md). The shared technologies are documented in
`docs/game_description/generic/technologies/`.
